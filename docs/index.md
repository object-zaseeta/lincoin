# Lincoin

AI がコードを書き、機械が検証し、人間は仕様の承認だけで出荷するプログラミング言語を作るプロジェクト。
GitHub で公開しながら進める(コミットログは英語)。

## 決まったこと

- 完成条件(エンドポイント)を測定可能な3条件に改訂し、測り方を固定した(11-01)
- v1.0 の射程は CLI ツール・データ処理・計算カーネル。汎用化は完成後(11-01)
- 独立 Git リポジトリとして GitHub で公開していく。コミットログは英語(11-01)
- 計算モデルは純粋・正格・静的型の関数型。正本は型付き ANF(10-28)
- メモリは領域推論主体、検証は篩型+SMT、副作用はケイパビリティ渡し(10-28)
